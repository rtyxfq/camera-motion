# 测量与校验

## 一、工具做什么

`tools/camera_motion.py` 把视频里的**画面运动**反解成四种量：

| 量 | 含义 | 单位 |
|---|---|---|
| `zoom_total` | 累计缩放（1.10 = 画面放大 10%） | 倍 |
| `norm_x` / `norm_y` | 横向/纵向累计位移 | 画面宽/高的比例 |
| `rot_deg_total` | 累计滚转 | 度 |
| `speed_norm_per_s` | 速度 | 画面比例/秒 |

**全部归一化成画面比例**，所以不同分辨率、不同画幅之间可比。

## 二、为什么只测画面四周的「背景带」

这是踩了三版才定下来的，不要改回去。

早期版本用全画面拟合，结果在真片上全错。同一个首尾帧对，分区测量的结果：

```
全画面   zoom=0.94  rot=-4.28°   ← 被主体带跑，连方向都反了
上带     1.098 / -0.21°          ← 背景，稳定
左柱     1.118 / -0.21°
右柱     1.101 / -0.16°
下带(地面) 0.368 / -10.82°       ← 运动模糊，直接崩
```

根因：**主体在画面里长大/移动，会主导全画面的特征点匹配**。

所以现在的策略是：只在四周背景带里**检出**特征点（中间主体区不参与），
但跟踪时**用整帧**（否则大幅平移时点会跑出区域被裁掉——这个坑也踩过，
下移 45px 只测出 12.8px）。

各区域分别拟合后，用 MAD 剔离群、取中位数。区域间不一致就明确报低置信度。

## 三、置信度怎么读

| 置信度 | 含义 | 怎么用 |
|---|---|---|
| 高 | 各背景区读数一致 | 可以当结论用 |
| 中 | 基本一致，有视差差异 | 可用，注意是近似 |
| 低 | 各区不一致 | **只作参考，必须人眼看抽帧** |
| 不可判 | 背景不足 / 区域数 < 2 | **没有结论**，不要猜 |

「不可判」是**正确行为**，不是 bug。特写镜头背景不可见时，任何测量都不可信——
宁可拒绝作答，也不给一个看起来专业的错数。

## 四、自检（改代码后必跑）

```bash
python tools/camera_motion.py --selftest
```

四项全绿才能信任测量结果：

1. **精度**：合成已知旋转/缩放，误差要 < 0.15° / < 0.005
2. **方向符号**：内容右移必须判成 Pan Left（这条修过一次，回归必测）
3. **主体污染**：主体角点压过背景时，应拒绝作答而非给错数
4. **阴性对照**：背景充足时必须正常作答（防止阈值过严）

## 五、校验 prompt 有没有生效

```bash
python tools/camera_motion.py --video 产出.mp4 --check-prompt 胶囊.md
```

它把 prompt 文本里出现的运镜词，和实测判读做比对：

- **直接对应**：写的和测出来的一致
- **同族对应**：方向对但措辞不同（Pan↔Truck 这类，2D 里本就不分）
- **实测没有**：写了但没发生
- **漏写**：没写但发生了

## 六、「实测没有」怎么归因

这是整个流程里最有价值的一步，因为它能把「prompt 不好」和「模型不行」分开。

**第一步：看是不是测量误差。**
- 置信度低或不可判 → 先看抽帧，别急着改 prompt
- 主体占满画面 → 测不出来，换构图或人工判读

**第二步：一次只改一处，再跑一次。**

| 怀疑 | 改法 |
|---|---|
| 表述不够明确 | 补幅度 / 速度修饰 |
| 动词不对路 | 换成更直接的动词 |
| 被其它描述稀释 | 加强显式约束（例如显式写固定） |
| 模型本身弱 | 换运镜方案 |

**记录结果。** 每次「改了什么 → 测出什么」都要留下，
这是 `models/<model>.md` 里「已知失败模式」的唯一正当来源。

## 七、标定怎么做

目标是拿到「模型听到某个词，实际给多少」的映射。

**控制变量**：
- 同一张首帧 / 同一主体 / 同样时长与分辨率
- 同种子（如果工作流允许）
- **只改运镜那一个变量**

**样本量**：每组 ≥3 条。单条会被随机性骗。

**读数**：用 `zoom_total` / `norm_x` / `norm_y` / `speed_norm_per_s`，取中位数。

**记录格式**（写进 `models/<model>.md`）：

```
large amplitude  → 实测 zoom 1.__ ~ 1.__（n=3, 2026-__-__, 5s/768p/4step）
```

没做过的就留 `⬜ 未标定`。**不要用行业常识填。**
