# 通用运镜运动学

跨模型通用的部分：**每种运镜在画面上到底改变了什么**。
不涉及任何模型的词表（那是 `models/` 的事）。

## 一、先分清三组最容易混的

### 1. 推/拉（机位动） vs 变焦（机位不动）

| | 机位 | 焦距 | 画面差异 |
|---|---|---|---|
| **Push / Pull**（推拉） | 前进 / 后退 | 不变 | **有视差**：近景长得快，远景长得慢 |
| **Zoom**（变焦） | 不动 | 变化 | **无视差**：整幅画面等比缩放 |

**怎么判**：把一个镜头内各区域的缩放系数分别拟合，看离散度。
一致 → Zoom；不一致（近处快） → Push/Pull。
`camera_motion.py` 就是按这个判的（`parallax_ratio`）。

**视觉差别**：Push 会有空间穿行感、背景相对变形；Zoom 像把人拉近，空间关系不变，更"平"。

### 2. Pan（摇头） vs Truck（横移）

**2D 画面里物理不可分**——两者都是「内容整体横向平移」。
真实区别在视差：Truck 有前景/背景位移差，Pan 没有（纯旋转）。

但短镜头、浅景深、缺少近景参照时，两者测出来几乎一样。
**所以工具同时给两个候选，由人按原片判断。** 别假装能自动分开。

### 3. Tilt（俯仰） vs Pedestal（升降）

同上，都是「内容整体纵向平移」。

## 二、符号约定（最容易搞反的地方）

工具输出的是**画面内容**往哪移，不是相机往哪转：

| 画面内容 | 相机实际动作 |
|---|---|
| 向右移 | 相机向**左**摇 / 左移（`Pan Left` / `Truck Left`） |
| 向左移 | 相机向**右**摇 / 右移（`Pan Right` / `Truck Right`） |
| 向下移 | 相机**上**仰 / 上升（`Tilt Up` / `Pedestal Up`） |
| 向上移 | 相机**下**俯 / 下降（`Tilt Down` / `Pedestal Down`） |

⚠️ 横向与纵向的直觉相反：横向「内容右移 = 相机左转」，纵向「内容下移 = 相机上仰」。
这不是笔误，`camera_motion.py --selftest` 的「自检 2」专门守这一条。

## 三、各运镜的用途

| 运镜 | 做的感觉 | 常见误用 |
|---|---|---|
| Push In（推近） | 聚焦、逼近、揭示重要性、压迫 | 推太多次会廉价 |
| Pull Out（拉远） | 收尾、孤立、揭示环境、失落 | 情绪高点拉远会泄气 |
| Zoom | 观察、窥视、扁平化 | 想要空间感时误用（该用 Push） |
| Pan | 扫视环境、跟随视线、揭示 | 想跟人物时误用（该用 Truck） |
| Truck | 平行跟随、横移展示 | 想扫景时误用（该用 Pan） |
| Tilt | 上下打量、揭示高度 | 想展示地面细节时方向写反 |
| Pedestal | 升降揭示、被遮挡物出现 | 与 Tilt 混用 |
| Arc（环绕） | 英雄感、立体感、关系展示 | 短时长里跑不完一圈（已实测：5.2s 有人物下做不出环绕，仅「横移+人物转」。见 `calibration-arc-p3-2026-11-09.md`） |
| Tracking（跟随） | 保持与运动主体的关系 | 主体不动时无意义 |
| Roll（滚转） | 失控、颠倒、晕眩 | **超过约 15° 观感会像「画歪了」而非刻意** |
| Shake | 手持、混乱、冲击 | 全片抖会疲劳 |
| Static（固定） | 稳定、客观、让画面自己说话 | 以为「不写就是固定」——未必 |

## 四、幅度与速度是独立两维

这是很多 prompt 失败的地方：只写了动词。

- **幅度** = 变化范围有多大（动得远不远）
- **速度** = 变化得多快（单位时间动多少）

「大幅慢速」和「小幅快速」是完全不同的观感，不能只写一个。
两者都省略时，模型按自己的默认走——**而默认值因模型而异，必须实测**。

## 五、一次只写一种运动

多个运镜叠在一起时，模型很可能只执行其中一个，或者抖成四不像。
实测反例：某条同时写了 push + tilt + roll，结果滚转累计 27.9°，观感是画面歪了。

需要复合运动时，优先拆成多个镜头，而不是堆在一个镜头里。

## 六、构图与运镜是耦合的

一个运镜能不能成立，取决于构图留没留出余量：

- **推近**需要画面边缘有可被推掉的余量，主体贴边就推不动
- **拉远**需要画外有内容可揭示，否则拉出来就是空
- **Pan/Truck** 需要有横向延伸的空间
- **主体占满画面时，几乎测不出也做不了运镜**（背景不可见）

选运镜前先看构图，别反过来。
