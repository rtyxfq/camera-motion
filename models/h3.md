## 词表（官方原样照抄，§4.3）

官方表格共 **12 个 `Motion type` 行**（多数成对出现，展开后 24 个词）+ 2 档幅度 + 2 档速度。
以下逐行照抄，未增删。

| 官方词 | 含义 | 备注 |
|---|---|---|
| `Zoom In` / `Zoom Out` | 焦距变化，机身不动 | |
| `Push In` / `Pull Out` | 机身前进 / 后退 | |
| `Pan Left` / `Pan Right` | 机身不动，镜头水平旋转 | |
| `Truck Left` / `Truck Right` | 机身水平横移 | |
| `Tilt Up` / `Tilt Down` | 机身不动，镜头垂直旋转 | |
| `Pedestal Up` / `Pedestal Down` | 整机上升 / 下降 | |
| `Arc Shot` | 沿弧线绕主体 | |
| `Tracking Shot` | 跟随运动主体 | |
| `Static Shot` | 机位与镜头均不动 | |
| `Shake Slightly` / `Shake Strongly` | 轻微 / 强烈抖动 | |
| `POV` | 主体视角 | |
| `Roll Clockwise` / `Roll Counterclockwise` | 绕镜头轴滚转 | |

**幅度**（§4.3）：`with small amplitude` / `with large amplitude`
**速度**（§4.3）：`at slow speed` / `at fast speed`

官方明确说明：**中等幅度与正常速度通常省略不写**（默认值）。

## 通用说法 → H3 写法

### 判定分四档（别把前两档混为一谈）

| 标记 | 含义 | 依据强度 |
|---|---|---|
| ✅ | 直接对应，换词即可 | 官方词表可查证 |
| 🔶 | 官方未列，但有**近似**官方词可用 | 推断，语义有损 |
| ❌ | 官方词表**确认无**此类 | 可查证（仅代表"官方没列"） |
| ⬜ | 官方未列，**模型可能仍能理解** | **纯未知，需 P1 实测** |

⚠️ 关键区别：**`❌` 只证明「官方没列」，不等于「H3 做不到」。**
官方原文用的是 "Available Expression"，全文没有任何一句说这是封闭集合；
ref2va 那份更只写 "Write camera movement as natural English"，连词表都不给。
所以下列所有 `⬜` 项，在 P1 实测前**不得当作结论使用**。

### 直接对应（✅ 可查证）

| 你可能写的 | H3 写什么 |
|---|---|
| dolly in / slow push | `Push In` |
| dolly out / pull back | `Pull Out` |
| zoom in / zoom out | `Zoom In` / `Zoom Out` |
| pan left / pan right | `Pan Left` / `Pan Right` |
| truck / track left / right | `Truck Left` / `Truck Right` |
| tilt up / tilt down | `Tilt Up` / `Tilt Down` |
| pedestal / boom up / down | `Pedestal Up` / `Pedestal Down` |
| arc / orbit / 360 | `Arc Shot` |
| follow / tracking / 跟拍 | `Tracking Shot` |
| static / locked off / 固定机位 | `Static Shot` |
| handheld / slight shake | `Shake Slightly`（注意：是抖动，不是手持质感） |
| shaky cam / 剧烈抖动 | `Shake Strongly` |

### 有近似官方词（🔶 推断，语义有损）

| 你可能写的 | 退而求其次 | 丢了什么 |
|---|---|---|
| crash zoom / snap zoom | `Zoom In` + `large amplitude` + `at fast speed` | 突变感，只能靠三维度逼近 |
| crane shot / jib up | 近似 `Pedestal Up` | crane 是弧线上升，Pedestal 是纯垂直，**不等价** |
| side tracking shot | `Truck Left` / `Truck Right` | 无（这其实就是横移跟拍） |
| top-down tracking | `Tracking Shot` + 机位描述 | 官方词只表达"跟随"，不表达"俯视"，俯视要靠构图文字说明 |
| sweeping shot | `Pan` 或 `Truck` + `large amplitude` | 无专门词，靠幅度表达 |

## 已知失败模式

只列**有证据**的。

| 现象 | 证据 | 应对 |
|---|---|---|
| **prompt 明确写了运镜，产出却静止** | 两条 prompt 共用同一骨架（含 "The camera stays low and dollies in slowly, tilting up slightly"）：<br>`L2T_S1` 实测 **Static Shot**（置信度高）<br>`L2T_S2` 实测 **Push In + 放大 17.5%**（置信度高）<br>→ 同 prompt 不同风格，一条照做一条没有 | 必须逐条校验，不能假定生效 |
| **多运镜叠加时滚转失控** | 一条 10s 视频镜头 3 同时含 push + tilt + roll，实测滚转累计 **27.9°**，观感是画面歪了 | 滚转单独使用；幅度过大时慎用 |
| **特写镜头测不出运镜** | 主体占满画面时背景带无可用特征点，工具报「不可判」 | 换构图，或人工判读；不要相信低置信度读数 |
| **H3 会把长 prompt 自动分镜** | 一条 10.12s 产出被切成 3 个镜头（切点帧 82、98），而 prompt 未要求切镜 | 想要一镜到底需显式声明；多镜头要按 `[Shot N] At MM:SS.mmm` 写 |

## H3 特有约束

- **运镜写在 `integrated_multimodal_description` 的 `[Shot N]` 正文里**，写成自然英文句子，
  **不要写成 `[Push in]` 这种括号标签**（官方模板明确要求 natural English action）。
- **格式规范不在本文件范围**。字段名、段落顺序、`<Picture N>` 编号、
  `[Shot N] At MM:SS.mmm` 时间戳等，一律以官方 skill `h3-prompt-writing` 为准。
- **`<Video N>` 可以搬运镜**。ref2va 模式下官方明确支持：
  "Referencing the original video's camera movement, cuts, rhythm, or temporal structure"，
  任务类型归 `[reference generation]`。
  → 这条通道比文字词表更直接，但**本机尚未验证迁移准确度**。
- 有社区说法称「不写 Static Shot 时 H3 默认会漂移」。
  ⬜ **未验证**，且与上表第一条失败模式（`L2T_S1` 未写运镜、产出静止）表面矛盾。
  需要单一变量对照才能定论。

## 待验证

按优先级排列。**P1 标定要回答的就是这张清单。**

### P1 必测（决定词表与阈值能不能下结论）

- [ ] **高**：词表是否封闭？写 `dolly in` 与写 `Push In`，实测结果有无差异？
      这是所有 `❌`/`⬜` 判定的上游问题——不答这一条，其余判定都只能标"未知"。
- [ ] **高**：`whip pan` 到底管不管用？
      本机 3 个工作流在用它，官方未列。**这是"正在使用却可能无效"的最高风险项。**
      对照：A 不写运镜 / B 写 `whip pan` / C 写 `Pan Right at fast speed`
- [ ] **高**：不写任何运镜词时，H3 默认静止还是漂移？（单一变量对照，≥3 条）
      注：社区有"默认必漂"的说法，但本机 `L2T_S1` 未写运镜词、实测为静止，与之说矛盾。
- [ ] **高**：`small` / `large` amplitude 实际对应多少 % 画面位移？
- [ ] **高**：`slow` / `fast` speed 实际对应多少 %画面/秒？

### P1 顺带测（成本低，影响写法）

- [ ] **中**：`Static Shot` 显式声明是否真能抑制漂移？
- [ ] **中**：中文写运镜描述 vs 英文写，哪个更听话？
      官方 skill 要求英文；社区整理的 `minimax-h3-prompt-optimizer`（dsh-film 插件内，未生效）
      主张中文等效。两者冲突，只能实测。
- [ ] **中**：`<Video N>` 搬运镜的保真度——给了推镜参考，产出到底推不推、推多少？

### 低优先级 / 已知观察

- [ ] **低**：滚转在什么阈值以上会「像画歪了」而非刻意（当前观察：27.9° 已过头）
- [ ] **低**：复合运镜（push + tilt）是否比拆成两镜更差
